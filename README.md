# CS231 — Flying Car Hand Gesture Recognition

This repository contains all source code, training notebooks, and evaluation utilities for the **Hand Gesture Detection** project built for the CS231 course.

## Repository Structure

```
ProjectFlyingCar/
├── DuyAnh/          # Duy Anh's independent work and prototype models
└── QuocKien/        # Quoc Kien's full detection pipeline (see README inside)
```

## Team Members

| Member | Folder | Responsibility |
|--------|--------|----------------|
| Quoc Kien | `QuocKien/` | End-to-end detection pipeline (ResNet18, MobileNetV2, YOLO11n), real-time inference |
| Duy Anh | `DuyAnh/` | Gesture classification prototype and OpenCV tooling |

## Quick Start

Navigate into the member folder you want to explore and follow the README inside.

```bash
cd QuocKien
# See QuocKien/README.md for full setup and run instructions
```
